# Harsh Verma — Portfolio

My personal portfolio website — modern dark responsive portfolio built with pure HTML/CSS/JS (single `index.html`).

**Live:** after GitHub Pages setup → `https://harsh17908.github.io/personal-portfolio/`
**Repo:** https://github.com/harsh17908/personal-portfolio

## Run locally
Just open `index.html` in a browser, or:
```powershell
python -m http.server 8000
# then visit http://localhost:8000
```

## GitHub Pages
1. Repo → Settings → Pages → Deploy from branch → `main` / `/ (root)` → Save
2. Your site will be live in ~1 min at https://harsh17908.github.io/personal-portfolio/

## Customize
Edit `index.html`:
